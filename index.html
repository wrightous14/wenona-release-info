Software updates, carefully managed.

Wenona Release Automation is a personal-use tool for publishing reviewed software updates to the privately accessed Wenona Cottage Tracker application.

What the authorization does

When the owner grants Google permission, the release workflow can manage Google Apps Script project code and versions, and update an existing deployment. It is used only for software maintenance.

The release workflow is restricted to the owner's GitHub repository and requires an explicitly approved production run. It does not request Google Gmail, Google Drive, or Google Sheets OAuth scopes.

Who can use it?

Only the authorized owner uses this deployment automation. This informational website is public for transparency; it does not provide access to the private tracker, its financial records, or its Google Sheet.

More information

Read our privacy policy and terms of use. Questions about this site or the release utility can be directed to the project owner on GitHub.
